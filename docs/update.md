# Обновление

```sh
cd /opt/sitecms && docker compose pull && docker compose up -d
```

Compose скачает свежий образ движка и пересоздаст контейнер. База и плагины
не трогаются: миграции догоняют схему при старте, папка плагинов лежит
снаружи.

Тот же результат даёт повторный запуск `install.sh`.

## Конкретная версия

В `docker-compose.yml` замените `ghcr.io/sitecms/engine:latest` на
`ghcr.io/sitecms/engine:v0.1.0` и выполните `docker compose up -d`. Так же
делается откат.

## Если что-то пошло не так

```sh
docker compose logs -f engine
```

Движок пишет, что не так с базой или с плагином. Сломанный плагин магазин
не останавливает — он помечается в «Плагинах» с текстом ошибки.
